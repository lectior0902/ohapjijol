## §0 공통 스타일 기준

모든 프롬프트 맨 앞에 아래 블록을 그대로 붙여 넣습니다. 이미지마다 붙여야 화풍이 흔들리지 않습니다.

```text
[공통 스타일]
정교한 16-bit~32-bit 인디 추리 RPG 픽셀 아트. 진짜 픽셀 아트로, 픽셀 하나하나가 의도적으로 배치되어야 한다.
- 명확한 픽셀 클러스터와 선명한 실루엣. 1픽셀 단위의 깔끔한 외곽선(완전한 검정 대신 각 색의 가장 어두운 단계 사용).
- 제한된 팔레트: 이미지 하나당 24색 이내. 피부·머리·옷마다 3~4단계 명암 램프.
- 조명: 왼쪽 위에서 오는 차분한 주광 하나 + 오른쪽 뒤의 약한 차가운 림라이트.
- 금지: 안티앨리어싱, 흐린 경계, 부드러운 브러시 질감, 사진 같은 표현, 큰 면적의 그라데이션, 디더링 남용, 노이즈 필터.
- 분위기: 추리 게임에 어울리는 차분하고 약간 어두운 톤. 채도는 중간 이하.
- 지나치게 귀엽거나 유아적인 SD/치비 비율 금지. 성인 비율(약 1:6.5 기준 상반신).
- 이미지 안에 글자, 숫자, 로고 문자, 워터마크를 넣지 않는다. (글자는 게임이 위에 따로 얹는다)
- 결과물은 확대해도 픽셀 격자가 정확히 맞아야 한다(정수 배율, 픽셀 아님 왜곡 없음).
```

## §1 인물 초상

### 공통 규격 (인물)

```text
[인물 공통 규격]
- 원본 캔버스 128×128 픽셀, 투명 배경(PNG). 캐릭터 이외의 배경·바닥 그림자 없음.
- 구도: 3/4 정면(시선은 화면 정면 또는 약간 왼쪽), 머리 꼭대기부터 가슴 중간까지 나오는 상반신 바스트샷.
- 머리 꼭대기는 위에서 약 10px, 어깨선은 아래 가장자리에 걸치게. 다섯 명 모두 머리 크기와 눈높이가 같아야 한다(눈 위치 y≈52).
- 다섯 명 모두 29세 한국인 성인 여성. 같은 중학교 방송반 출신 친구들.
- 피부 램프는 다섯 명이 같은 팔레트를 공유하고, 머리·옷 색만 인물마다 다르다.
- 인물마다 '고정 2색 + 포인트 1색'으로 실루엣만 봐도 구별되게.
```

### 1-1. 스타일 테스트 — 임주연 기본 (가장 먼저)

```text
[공통 스타일] + [인물 공통 규격]

인물: 임주연, 29세 여성. 이 이야기의 피해자. 사진 속 인물로만 등장한다.
외형: 어깨선까지 오는 흑갈색 생머리, 앞머리 없음, 가운데 가르마. 회색 후드티(후드 끈 두 줄)와 검은 조거.
왼쪽 귀(화면 기준 오른쪽)에 작은 은색 링 피어싱 3개. 눈 밑에 옅은 다크서클. 지쳐 보이지만 단정한 얼굴.
표정: 기본. 입을 다문 채 담담하게 정면을 본다. 미소는 아주 약하게.
팔레트: 차콜 / 블랙 / 실버 포인트.
```

이 결과물로 **픽셀 밀도, 외곽선 굵기, 명암 단계, 팔레트**를 확정합니다. 이후 모든 프롬프트에 `위 기준 이미지와 같은 화풍·픽셀 밀도·조명·비율로` 를 붙이고 기준 이미지를 함께 첨부합니다.

### 1-2. 나머지 네 명 — 기본 표정

각 프롬프트 앞에 `[공통 스타일] + [인물 공통 규격] + 기준 이미지(임주연 기본)와 같은 화풍·픽셀 밀도·조명·비율로` 를 붙입니다.

**박지영 (에코미디어 대표)**

```text
인물: 박지영, 29세 여성. 바이럴 대행사 대표. 차분하고 계산적이며, 자신이 피해자라고 믿는 사람.
외형: 턱선 길이의 검은 단발, 끝이 안쪽으로 살짝 말림. 큰 투명 뿔테 안경(테는 반투명한 연한 베이지, 렌즈에 작은 하이라이트 두 점).
베이지 트렌치코트 + 흰 셔츠(옷깃이 보이게). 왼손목에 스마트워치(이번 구도에서 안 보이면 생략).
표정(기본): 입꼬리만 올라간 웃음. 눈은 웃지 않는다.
팔레트: 베이지 / 화이트 / 로즈골드 포인트.
```

**전채은 (유튜버 '채온')**

```text
인물: 전채은, 29세 여성. 구독자 80만 유튜버. 카메라 앞에 익숙하고 말이 빠르다.
외형: 애쉬 블론드 긴 웨이브 머리(가슴까지). 검은 오버사이즈 후드티, 가슴에 작은 형광 그린 로고 모양(글자 없이 형태만).
목에 형광 그린 헤드셋을 걸고 있다. 눈동자에 링라이트 반사광(작은 흰 고리). 손톱은 빨강(손이 보이면).
표정(기본): 입이 살짝 열려 있다. 말하다 멈춘 듯한 얼굴.
팔레트: 블랙 / 네온그린 / 레드 포인트.
```

**성지인 (넥스트웨이브 홍보이사)**

```text
인물: 성지인, 29세 여성. 스타트업 홍보이사. 단정하고 감정을 드러내지 않는다.
외형: 검은 머리를 낮게 묶은 포니테일(목 뒤로 꼬리가 살짝 보임), 잔머리 없이 깔끔. 네이비 수트 재킷 + 연회색 이너.
목에 사원증 목걸이(흰 카드에 파란 물결 두 줄 무늬, 글자 없음). 오른쪽 귀(화면 기준 왼쪽 또는 보이는 쪽)에 흰 무선 이어폰 한쪽.
표정(기본): 얇은 입술을 다문 무표정. 시선은 정면.
팔레트: 네이비 / 라이트그레이 / 웨이브블루 포인트.
```

**정가연 (동네 책방 '책방 가연' 운영)**

```text
인물: 정가연, 29세 여성. 작은 동네 책방 주인. 다정하지만 무언가를 숨기고 있다.
외형: 짧은 갈색 커트(귀가 드러나는 길이). 올리브색 상의 위에 크림색 린넨 앞치마, 앞치마 주머니에 연필 한 자루.
손목에 여러 색의 색실 팔찌(손이 보이게 구도를 잡을 경우). 커피 드립 서버를 한 손에 든 버전은 §1-4 선택 항목.
표정(기본): 눈웃음(눈이 반달 모양).
팔레트: 올리브 / 크림 / 테라코타 포인트.
```

## §2 갤러리 장면

사진첩 안의 '사진'입니다. 배경이 있는 완성 장면이므로 **불투명 PNG**로 만듭니다. 타임스탬프·REC 표시 같은 글자는 게임이 위에 얹으니 넣지 않습니다.

```text
[장면 공통 규격]
- 인물은 §1의 기준 이미지와 같은 사람으로 읽혀야 한다(머리 모양·옷 색·소품). 장면 속 인물은 전신 또는 반신, 작은 크기.
- 장면 안에서도 같은 팔레트 원칙(이미지당 32색 이내)과 픽셀 규칙을 지킨다.
- 글자·숫자·타임스탬프 금지.
```
