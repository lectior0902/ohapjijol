# 오합지졸 — 엔딩 이미지 생성 프롬프트

**Generation Tool:** Gemini
**Style reference:** 기존 통합본 §0 MASTER STYLE을 그대로 앞에 붙인다.
**Delivery:** 생성 원본을 이름 그대로 `assets/pixel/_원본/`에 넣고 알려 주면 정리(로고 제거·축소·이름 지정)는 Claude가 한다.

## 왜 필요한가

| 엔딩 | 지금 | 이 문서로 추가 |
|---|---|---|
| 트루 | 신문 사진 = 증거 봉투 속 휴대전화(`byjy`) ✅ | **E-1 마지막 장면**(필수 권장): 에필로그 마지막 카드 "[작업실 2] 님이 초대했습니다… 화면 꺼짐"에 붙는 그림 |
| 의혹 제기 | 사진 없음(글만 있는 지면) | E-2 (선택) |
| 배드 ① 자살 | 사진 없음 | E-3 (선택) |
| 배드 ③ 성지인 | 사진 없음 | E-4 (선택) |
| 배드 ④ 전채은 | 사진 없음 | E-5 (선택) |

E-1은 **타이틀(`ej1o`: 어두운 탁자 위 휴대전화, 창밖 야경)과 같은 구도**로 만든다. 게임의 처음과 끝이 같은 장면이 되고, 끝에서만 화면이 켜진다.
E-2~E-5는 신문 지면 사진이다. 게임이 흑백 필터를 씌우므로 컬러로 만들어도 된다. 파일이 없는 엔딩은 지금처럼 사진 없이 표시된다.

공통 규칙(전부):
- 최종 크기 **240 × 134** (16:9, 타이틀과 같은 픽셀 밀도). 생성은 2752×1536 등 16:9면 된다.
- 사람 얼굴을 그리지 않는다(E-1~E-5 모두 인물 없음).
- 글자·숫자·로고·UI·알림 문구 금지. 알림 문구와 캡션은 게임이 따로 얹는다.

## E-1 트루 엔딩 마지막 장면 — `screen_ending_invite.png` (권장)

**Reference images:** 타이틀 이미지(`ej1o`)를 구도·조명·소품 기준으로 첨부한다.

### Prompt

Using the provided title image as the exact composition reference, create the same scene a moment later.

The same dark wooden desk, the same smartphone in the same position and angle, the same window with the same night city view. Keep the camera angle, framing, objects, and palette identical.

The only change: the smartphone screen has just lit up. A soft, cold white-blue glow spreads from the screen onto the desk surface and faintly onto the nearby wall. On the screen there is a single blank notification card shape near the top (a plain rounded rectangle, no text, no icon details).

The rest of the room remains dark and still. The mood is quiet and ominous rather than dramatic: something new has started, and no one is there to see it.

Follow the shared OHAPJIJOL 16-bit pixel-art style. No people. No readable text, letters, numbers, logos, or UI labels.
