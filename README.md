# 오합지졸 — 잠신일보 디지털 포렌식 파일

폰 하나, 용의자 네 명, 질문 스무 번. 잠신일보 디지털탐사팀 기자가 되어 한 사람의 죽음을 취재하는 웹 추리 게임. 플레이타임 30~40분.

## 실행

빌드가 필요 없는 정적 사이트다. `fetch`로 `data/game.json`을 읽기 때문에 파일을 직접 열지 말고 로컬 서버로 띄운다.

```
python -m http.server 8000
```

## 구조

```
index.html          진입점
css/style.css       폰 프레임·앱·엔딩 스타일
src/state.js        상태, 저장(localStorage), 조건 판정
src/phone.js        잠금화면·홈·앱 6종(문자/텔레그램/메모/갤러리/SNS/인터넷)
src/interview.js    취재 수첩: 루트 A/B 질문, 심화, 추궁(부분 자백)
src/events.js       돌발 이벤트 3종(국과수 속보·기습 전화·국장 독촉)
src/ending.js       증거함, 기사 쓰기, 엔딩 판정
data/game.json      모든 텍스트와 규칙 (원본: docs/01_시나리오_설계.md)
```

모든 대사·데이터의 원본은 [`docs/01_시나리오_설계.md`](docs/01_시나리오_설계.md)다. 문구를 고치면 문서도 같이 고친다. 초상·갤러리 그림은 현재 플레이스홀더이며 픽셀 아트는 2차 작업이다.

이 게임의 인물·기업·매체·사건은 모두 허구다.
