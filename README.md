# 오합지졸 — 잠신일보 디지털 포렌식 파일

폰 하나, 용의자 네 명, 질문 스무 번. 잠신일보 디지털탐사팀 기자가 되어 한 사람의 죽음을 취재하는 웹 추리 게임. 플레이타임 30~40분.

## 실행

빌드가 필요 없는 정적 사이트다. `fetch`로 `data/game.json`을 읽기 때문에 파일을 직접 열지 말고 로컬 서버로 띄운다.

```
python -m http.server 8000
```

## 구조

```
index.html          진입점
css/*.css           style(기본) → theme(앱별 테마) → extra(픽셀·메일·타임라인·관계도)
src/state.js        상태, 저장(localStorage), 조건 판정
src/phone.js        잠금화면·홈·앱 7종(메시지/텔레그램/메모/갤러리/SNS/인터넷/메일)·기사 페이지
src/interview.js    취재 수첩: 루트 A/B 질문, 심화, 추궁(부분 자백), 타임라인, 관계도
src/pixel.js        픽셀 아트(초상·장면·장소 배경)를 캔버스로 그림
src/sound.js        효과음(WebAudio 합성)
src/events.js       돌발 이벤트 3종(국과수 속보·기습 전화·국장 독촉)
src/ending.js       증거함, 기사 쓰기, 엔딩 판정
data/game.json      모든 텍스트와 규칙 (원본: docs/01_시나리오_설계.md)
```

모든 대사·데이터의 원본은 [`docs/01_시나리오_설계.md`](docs/01_시나리오_설계.md)다. 문구를 고치면 문서도 같이 고친다. 인물·장소·사진은 코드로 그린 픽셀 아트, 문서류(영수증·합의서·기사)는 HTML로 그린다.

이 게임의 인물·기업·매체·사건은 모두 허구다.
